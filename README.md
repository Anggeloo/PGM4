# PGM4 Node.js project: Fruit List
This project is a basic web application developed with Node.js and Express. When executed, it generates a list of fruits in HTML format that is displayed in the web browser.

## Note: This project currently does not include a Dockerfile. However, it can easily be adapted to run in a Docker container if needed.

## 💻 Technologies Used
- Language: JavaScript (ES6)
- Environment: Node.js
- Framework: Express

## ✅ Requirements
1. Install Node.js
- Minimum recommended version: 16.x or higher.

2. NPM or Yarn package manager:
- Comes bundled with Node.js.
- Check your NPM version by running:
```bash
npm -v
``` 

## 🚀 How to Execute
1. Clone this repository:

```bash
git clone https://github.com/Anggeloo/PGM4.git
```

2. Navigate to the project directory:
```bash
cd PGM4
```

3. Install the project dependencies:
```bash
npm install  
```

4. Run the server:
```bash
node PGM4.mjs
``` 

5. Open your browser and access the URL:
```bash
http://localhost:3000
```

## 🌐 Online project.
